# JC. favicon image

Created with the built-in `image_gen` tool at 1254 × 1254 and exported as a compact 256 × 256 PNG at `src/app/icon.png`. This replaces the previous SVG tab icon through Next.js file-based icon metadata.

Final prompt:

```text
Use case: logo-brand. Asset type: square browser tab favicon image for a professional software engineer portfolio. Create a clean, perfectly flat typographic monogram icon. Exact visible text: "JC." — uppercase J followed immediately by uppercase C, followed by a distinct circular dot. J and C must be pure white (#FFFFFF); ONLY the terminal dot must be bright cyan (#22D3EE). The entire square background must be solid pure black (#000000), edge to edge. Heavy, modern geometric sans-serif lettering similar to an extra-bold Manrope wordmark, crisp simple letterforms, tight but legible spacing. The J must be clearly a J with a lower hook and the C clearly an open C. Put the white JC and cyan dot on the same baseline as one centered horizontal wordmark, optically centered in the square. Use large lettering that occupies roughly 76 percent of the square width, with balanced safe margins; the cyan dot should remain visible when the entire image is reduced to a 16-pixel browser favicon. Square composition, 1:1 aspect ratio. No other letters, no borders, no shadows, no gradients, no glow, no bevels, no textures, no frame, no mockup, no watermark, no extra symbols. Output just the actual black-square icon, not an icon displayed on a device or webpage.
```
